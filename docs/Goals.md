# Goals

Targets for numbers that other modules already keep, or for a number you update by hand.

## Add a goal

On the right: a **Goal** name, **Measured by**, the **Aim** and the **Target**.

- **Measured by** is either **By hand** or one of the numbers a switched-on module offers, for example: tasks done in the last 7 days or this month, focus minutes, money saved or spent this month, habits done in the last 7 days, days journalled this month, workout minutes, water and sleep averages, items finished in the Library this year, hours tracked this week, the value of your stocks. The list only shows what your modules offer right now.
- **Aim** is **Reach at least** (a savings goal, tasks done) or **Stay under** (a spending limit).

## Follow it

Each goal has a bar, the value against the target, and **Reached**, **Over the limit** or the percentage. It reads the other module live, so the number is always current.

- A goal **By hand** has `−` and `+` (a step of one twentieth of the target) and a box to type the value.
- If the module that measures a goal is switched off, the goal says so instead of showing a wrong number. Switch the module on again and it carries on.

Key: `N` new goal. Home shows how many goals are on track and warns about any over its limit; [Weekly Review](Weekly-Review.md) lists each goal's progress.
