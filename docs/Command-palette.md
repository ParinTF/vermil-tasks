# Command palette

`Ctrl+K` from anywhere opens a box. Type, use the arrows, press `Enter`; `Esc` closes it.

## Search

Type part of a title or a word from a note. Results mix, best match first:

- **Tasks** (open or done), **notes** (title and text) and **days**: type a date as words ("friday", "12/12") and "Open calendar on…" appears.
- **Commands** of the modules you have on: go to a tab, new task, new note, add an expense, look up a stock, start the time tracker, and so on. With nothing typed, the box lists the commands.

## Convert

Type a conversion and the answer comes first. `Enter` copies the result.

- **Units** (work offline): `5 km to mi`, `30 c to f`, `2 lbs in kg`, `100 km/h to mph`, `1 cup to ml`, `10 in to cm`. Length, weight, volume, speed and temperature.
- **Currency**: `100 usd to thb`. Vermil checks the internet first, asks for the rate (kept for ten minutes) and answers. Offline it says currencies need the internet; an unknown code says there is no rate.
