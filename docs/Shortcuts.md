# Keyboard shortcuts

Press `?` anywhere (outside a text field) for the live list; it shows only the modules you have on. Shortcuts use the physical key, so they work with a Thai layout.

## Everywhere

| Keys | Does |
|---|---|
| `Ctrl+0` or `Ctrl+,` | Home |
| `Ctrl+1` to `Ctrl+9` | The tabs in the order shown |
| `Ctrl+K` | [Command palette](Command-palette.md) |
| `?` | The shortcut list |
| `Esc` | Leave a field, close a dialog or menu |

## From any program in Windows

| Keys | Does |
|---|---|
| `Ctrl+Alt+T` | [Quick add](Quick-bar.md) a task |
| `Ctrl+Alt+N` | Quick note or link |
| `Ctrl+Alt+W` | Show or hide the [Today widget](Today-widget.md) |

If another program already uses one of these, the Shortcuts button in the footer gets a dot and the list says so; the tray menu has the same actions.

## In a module

Each module's own keys are in its guide. The most used:

- [Tasks](Tasks.md): arrows select, `Space` done, `E` edit, `P` pin, `N` new, `1`–`4` tabs, `Ctrl+F` search, `Ctrl+Z` undo.
- [Notes](Notes.md): `Ctrl+N` new, `Ctrl+B` bold, `Ctrl+Shift+L` checklist, `Ctrl+Enter` tick.
- [Calendar](Calendar.md): arrows move, `D` day view, `M` month, `T` today.
